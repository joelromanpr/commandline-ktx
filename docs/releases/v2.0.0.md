## What changed

- A validated `CommandSpec` now drives deterministic input descriptions and JSON Schema export.
- `parseStructured` accepts typed tool arguments and returns stable error codes and input provenance.
- The optional `commandline-ktx-mcp-bridge` artifact exposes MCP tool descriptors and validates arguments before an application handler runs.
- CLI parsing now rejects ambiguous definitions and extra positionals, and supports `--`, negative numbers, and `--name=value`.

## Upgrade from 1.0.0

`@OptionGroup` membership is explicit in 2.0.0. Add `group = "your-group"` to every intended `@Option` or `@Value` member. Unrelated flags should remain ungrouped. A declared group with no members now fails command validation. See the [migration example](https://github.com/joelromanpr/commandline-ktx#migrating-option-groups-from-100).

Both artifacts use version `2.0.0` and require Java 17.
